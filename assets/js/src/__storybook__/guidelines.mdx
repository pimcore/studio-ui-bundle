<h2 style={{ marginBottom: '1.5rem' }}>Writing style</h2>

<div style={{ fontSize: '14px', marginBottom: '2rem' }}>

**Title case for navigation**  
Menu items, tab titles, context menus, and labels shown when a menu item is opened in a tab use Title case, meaning each principal word is capitalized (e.g. Custom Reports, Output Channels). This ensures clear scannability in navigation and structural elements.

**Sentence case for actions**  
Buttons, modal titles, and other interactive elements with verbs or longer phrases use Sentence case, where only the first word is capitalized (e.g. Save draft, Merge version, Review changes). This emphasizes actionability and improves readability.

**Action-oriented wording**  
Use verb-first phrasing for all actionable interface elements. Static or noun-based labels, such as "CSV Export," should be reframed into active, action-oriented text like "Export CSV." Apply sentence case for buttons, menus, and other interactive elements to maintain readability and consistency. Use title case only when the phrase appears as a section heading or title (for example, "CSV Export"). This approach ensures a consistent tone across the interface and reinforces Pimcore's focus on clarity and usability.

</div>
