# Studio UI

The Studio UI Bundle provides a Backend UI for Pimcore. It is built using the [React](https://react.dev/) framework and [Ant Design](https://ant.design/).

You can access the Pimcore Studio Admin UI at its default URL: `{your-domain}/pimcore-studio`.
