# How to add a main nav entry

This example demonstrates how to add a new main navigation entry to the Pimcore Studio UI. This can be useful for extending the interface with custom tools or plugins.

![Main Nav Entry Example](../../assets/images/main-nav-entry-example.png)

New entries to the main navigation can be added via the `MainNavRegistry` service from the DI container. See the [main navigation entry example on GitHub](https://github.com/pimcore/studio-example-bundle/tree/main/assets/js/src/examples/main-nav-entry) to see how it works.
