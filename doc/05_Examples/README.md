# Plugin Development Examples

This section contains various examples to help you get started with plugin development for Pimcore Studio. Each example demonstrates a specific feature or functionality that you can implement in your plugins:

1. [How to register a new tab for a folder asset](./01_Register_a_tab_for_a_folder_asset.md)  
   Learn how to add a custom tab to the folder asset editor.

2. [How to add custom icons](./02_Adding_custom_icons.md)  
   Discover how to include and use custom icons in your plugin.

3. [How to add your first widget](./03_Add_your_first_widget.md)  
   A step-by-step guide to creating and integrating a widget into Pimcore Studio.

All these examples are part of the Pimcore Studio Example Bundle, which you can find on GitHub: [Pimcore Studio Example Bundle](https://github.com/pimcore/studio-example-bundle/). Feel free to explore the repository for more insights and code samples.
